On the Crest rendering. The header mascot is no longer hand-approximated — it's generated from the exact <rect> geometry in crest.svg on a 28×28 grid (4px source units), so every wing, eye and tail pixel matches the source. In the real TUI this maps to Unicode half-block (▀) ANSI art so each terminal row carries two pixel rows; the --plain / NO_COLOR path falls back to a small monochrome glyph.
