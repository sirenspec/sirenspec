# Recipe directory structure: one subdirectory per recipe under docs/cookbook/

Each recipe in the cookbook lives in its own subdirectory under `docs/cookbook/` (e.g. `docs/cookbook/telephone-game/`) containing a `workflow.yaml` and a Mintlify `README.mdx`. Locating recipes under `docs/` makes them first-class Mintlify content without a build step or copy script. The flat `examples/*.yaml` structure was migrated away from because it cannot accommodate companion files and makes user-submitted PRs harder to review. A separate `examples/` directory with a build-time copy to `docs/cookbook/` was rejected because it splits the canonical source from the rendered output and adds tooling complexity. A central `examples/index.yaml` was rejected because it creates a merge-conflict hotspot and decouples metadata from the recipe it describes.
